```bash
#!/bin/bash

    echo "✓ API healthy"

    echo "✗ API unhealthy - ALERT TRIGGERED"

# 2. Disk Space Check

if [ $USED_PERCENT -gt 85 ]; then
    echo "⚠️ Disk usage at ${USED_PERCENT}% - cleanup required"
else
    echo "✓ Disk space OK (${USED_PERCENT}%)"
fi

# 3. Database Size Check
DB_SIZE=$(du -sh ./data/audit.db | cut -f1)
echo "Database size: ${DB_SIZE}"

# 4. Redis Connection
redis-cli ping > /dev/null 2>&1
if [ $? -eq 0 ]; then
    echo "✓ Redis connected"
else
    echo "✗ Redis disconnected - restart required"
fi

# 5. Last Audit Timestamp
LAST_AUDIT=$(sqlite3 ./data/audit.db "SELECT audit_date FROM audits ORDER BY id DESC LIMIT 1;")
echo "Last audit: ${LAST_AUDIT}"

echo "=== OPERATIONS CHECK COMPLETE ==="
```

## 3. ARCHITECTURE DECISION RECORDS (ADR)

### ADR-001: Why SQLite Over PostgreSQL?

**Date:** 2026-09-15
**Status:** Accepted
**Decision:** Use SQLite for audit storage

**Context:**
- Single-writer workload (monthly audits only)
- No concurrent write contention expected
- Need for portable, single-file database
- Simplicity of backup/restore (copy file)

**Consequences:**
- Cannot scale horizontally
- Limited to ~100TB theoretical max
- Backup is file copy (no WAL archiving needed)
- Perfectly adequate for projected 5-year lifespan

### ADR-002: Why Flask Instead of Django?

**Date:** 2026-09-20
**Status:** Accepted
**Decision:** Use lightweight Flask microframework

**Context:**
- REST API only, no admin panels needed
- WebSocket support required (Flask-SocketIO)
- Team familiarity with Flask
- Faster startup time for serverless deployment

**Consequences:**
- Less built-in functionality than Django
- More manual ORM queries
- Greater flexibility for customization

### ADR-003: Citation Verification Convention

**Date:** 2026-10-01
**Status:** Accepted
**Decision:** Three-tier system (VERIFIED/UNVERIFIED/NOT_FOUND)

**Context:**
- Past audits failed due to unverified citations
- Legal liability for false statutory claims
- Need for transparent uncertainty communication

**Consequences:**
- Every table row carries tier column
- UNVERIFIED items bracketed with date stamp
- NOT FOUND phrased as "not found as of [date]"
- Failed citations documented in appendix
