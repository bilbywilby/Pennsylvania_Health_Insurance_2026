## Database Restore Procedure
```bash
# Step-by-step restore with verification
1. Identify backup timestamp: aws s3 ls s3://$BUCKET/backups/ --recursive
2. Download latest backup: aws s3 cp s3://$BUCKET/backups/latest.sqlite ./restore.db
3. Verify checksum: sha256sum ./restore.db vs. manifest
4. Stop services: docker-compose stop api worker
5. Replace database: mv ./data/audit.db ./data/audit.db.backup && mv ./restore.db ./data/audit.db
6. Run migrations: python src/migrations/run_migrations.py
7. Verify integrity: python src/validate_restore.py
8. Restart services: docker-compose start api worker
9. Confirm health: curl http://localhost:5000/api/health
10. Document in incident log
```
